# docs/: the issue folders

One folder per GitHub issue, named `issue<N>_<slug>`, holding the plan, the check script, and the tables, figures and summaries the script writes. Each folder's README says what changed, how to rerun it, what every file is, what was found and what the script asserts. Two conventions keep the folders honest: every number in a README or an issue comment comes from a table the check script writes and asserts, and the scripts read only what the last pipeline run left on disk plus the tracked tables, so a rerun gives byte-identical CSVs and PNGs. Local copies of pipeline outputs (`hoard/`) and drafts of issue comments (`issue<N>-*-comment.md`) are gitignored in every folder.
