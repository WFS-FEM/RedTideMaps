# Coastline (Natural Earth 1:10m, cropped to the WFS grid box)

`ne_10m_coastline_wfs.gpkg`: Natural Earth 1:10m physical coastline (public domain, https://www.naturalearthdata.com/downloads/10m-physical-vectors/), downloaded with `rnaturalearth::ne_download(scale = 10, type = "coastline", category = "physical")` on 19 October 2026 and cropped to the WFS grid box (-87.5 to -81 E, 25 to 30.5 N) by `docs/issue5_nearshore-hybrid-summary/subissues/issue8_nearshore-hybrid/check_nearshore_issue8.R` (issue #8), which recreates it when it is missing. It was moved here from `docs/issue5_nearshore-hybrid-summary/subissues/issue8_nearshore-hybrid/coastline/` in issue #11, when it became a pipeline input: `fn.nearshore_mask()` in `scripts/process_hybrid.R` (in `scripts/process_VIIRS.R` until issue #10) uses it for the distance-to-coast part of the `mask5` nearshore set (cells within 5 km of the coast). The pipeline does not download it; a missing file stops the run with a message.

At 1:10m the coastline resolves the large bays (Tampa Bay, Charlotte Harbor, Apalachicola Bay) but not every small inlet, so a distance to coast from it is good to about 1 to 2 km. One MULTILINESTRING feature, 122 KB; path exposed as `paths$file_coast` by `rt_paths()` in `scripts/_setup.R`.
